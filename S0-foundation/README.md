## 阶段目标

- Python 能写工程代码，不只会写零散脚本。
- Linux/Git 在自己的服务器上独立操作。
- PyTorch 能独立写训练和推理循环。
- Transformer 结构能白板画出、能手算关键维度。
- 本阶段不碰 C、不碰 CUDA。
