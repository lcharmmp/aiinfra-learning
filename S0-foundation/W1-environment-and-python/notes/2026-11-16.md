2. 列表是可变对象 老生常谈，之前：
```
# 错误：同一个列表会被多次调用共享
def collect_bad(x: int, result: list[int] = []) -> list[int]:
    result.append(x)
    return result

# 正确：用 None 表示“未提供”
def collect(x: int, result: list[int] | None = None) -> list[int]:
    if result is None:
        result = []
    result.append(x)
    return result

#现在：
#不要
class name:
    li=[]
    def __init__(self,):
    def add(self,x):
        self.li.append(x)
#而要
class name:
    def __init__(self,):
        self.li=[]
    def add(self,x):
        self.li.append(x)
```
